# catan

Pass on Java implementation of the popular boardgame "Settlers of Catan".
<br/>I wrote this in back in 2004 when home with a broken leg for a month.

Java Applets do not run in browsers any longer for security reasons.
<br/>A student in my class (Peter Lanszki) converted it to javascript with Claude in 2026.
<br/>It fixed my bugs, added a new look, network multiplayer, tutorial, translations, and chat.

I prefer the old look, that you can play at https://csurgay.github.io/catan-mp/
<br/>Or you can download the web directory and fire up the old Applet (Windows or Linux) by:
<br/>java -cp SettlersApplet.jar SettlersLauncher.java
